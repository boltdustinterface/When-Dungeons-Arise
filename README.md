## 📖 What Is When Dungeons Arise?

**When Dungeons Arise** is a massive structure generation mod by Aureljz that adds over 30 unique roguelike dungeons and structures to Minecraft. These aren't simple ruins — they're sprawling complexes with randomized rooms, corridors, and loot tables that pull from both vanilla and modded pools [citation:3][citation:15].

The mod has been downloaded over **50 million times** and continues to grow with every update. New dungeons are added regularly, and the mod is available for **Forge, NeoForge, and Fabric** across multiple Minecraft versions [citation:2][citation:19].

**Key highlights:**
- ✅ **30+ unique structures** — Fortresses, ships, mines, temples, and more

## ❓ FAQ

**Q: What is When Dungeons Arise?**
A: A massive structure generation mod that adds 30+ unique roguelike dungeons to Minecraft, from towering fortresses to airborne ships [citation:3].

**Q: Is When Dungeons Arise free?**
A: Yes — 100% free. Licensed under ARR (All Rights Reserved) [citation:13].

**Q: What Minecraft versions are supported?**
A: **1.16.5 – 1.21.1** and newer. The mod supports multiple versions across Forge, NeoForge, and Fabric [citation:3][citation:7].

**Q: Forge, NeoForge, or Fabric?**
A: All three are supported. Choose based on your mod loader [citation:2].

**Q: What does it require?**
A: **Fabric API** and **Cloth Config API** on Fabric versions. Forge/NeoForge versions have no additional dependencies [citation:14][citation:15].

**Q: How many structures are there?**
A: Over **30 unique structures**, with new ones added in updates [citation:15][citation:19].

**Q: How do I find dungeons?**
A: Use `/locate structure dungeons_arise:` followed by the structure name. Explorer's Compass and Structure Compass also work [citation:8].

**Q: Will structures generate in my existing world?**
A: Only in **new chunks**. Already-explored areas won't get new dungeons [citation:8].

**Q: Can I disable specific dungeons?**
A: Yes — edit the config or use a data pack to toggle individual structures [citation:1].

**Q: Can I change how often dungeons spawn?**
A: Yes — adjust `spacing` and `separation` values in the config. Higher values = rarer dungeons [citation:1].

**Q: Is it server-side only?**
A: Yes — it can run server-side only. Clients don't strictly need the mod, but mod-specific blocks may appear missing without it [citation:8].

**Q: What are the new enchantments?**
A: 1.21+ adds Purification, Ensnaring, Curse of Lolth, Voltaic Shot, and Discharge — each tied to specific structures [citation:5].

**Q: Does it work with other mods?**
A: Yes — compatible with most worldgen and structure mods. Loot tables pull from vanilla and modded pools [citation:8].

**Q: Does it work on Bedrock / mobile?**
A: No — **Java Edition only**.

**Q: How do I uninstall it?**
A: Delete the `.jar` from `.minecraft/mods/` and restart. Already-generated structures will remain in your world.
